03 / ประเมินความเสี่ยงฆ่าตัวตาย 8Q

โปรดดำเนินการตามแนวทางปฏิบัติของหน่วยงาน หากพบความเสี่ยงเร่งด่วน

โปรดตอบ 8Q ให้ครบเมื่อมีข้อบ่งชี้
สำคัญ: คะแนนและข้อความแปลผลเป็นเครื่องมือช่วยคัดกรอง ไม่ใช่การวินิจฉัย หากพบความคิดทำร้ายตนเองหรือความเสี่ยงเฉียบพลัน ต้องประเมินความปลอดภัยและส่งต่อทันทีตามแนวทางหน่วยงาน ไม่รอผลคะแนนรวม

การเชื่อมต่อ Backend

ใช้งานแบบ Standalone เพื่อทดลอง UI ได้ทันทีโดยใช้ข้อมูลตัวอย่างสมมติ เมื่อเปิดหน้าเว็บผ่าน Google Apps Script Web App ระบบจะสื่อสารผ่าน google.script.run โดยอัตโนมัติ

HTML Standalone ที่เปิดจากเครื่องหรือโฮสต์ภายนอกไม่สามารถรับประกันการเชื่อมต่อ Apps Script Web App ด้วย fetch ข้ามโดเมนได้ เนื่องจากข้อจำกัด CORS จึงแนะนำเผยแพร่หน้า HTML ผ่าน Apps Script สำหรับข้อมูลจริง

ความปลอดภัย: Backend อนุญาตเฉพาะอีเมลใน ALLOWED_EMAILS และปฏิเสธเมื่อไม่สามารถยืนยันอีเมลได้ • ห้ามเผยแพร่ Web App แบบ Anyone • ตั้งค่าการเข้าถึงข้อมูลในชีตตามสิทธิ์งานจริง
